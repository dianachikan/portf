# Ясми: числа и этапы исследований

Уточнено 15 ноября 2026 по исходным таблицам и пояснениям Дианы в чате. Этот файл задаёт актуальные числа для редакторской работы над кейсом. Числа из старого текста, ранней сводки контекста и постов не смешиваем между выборками.

## Формулировка для кейса

«На опрос ответили 69 человек. Для дальнейшего анализа я отобрала 50 участников, близких к целевой аудитории. Затем провела четыре исследовательских интервью».

Отдельный этап — первые неформальные тесты работающего продукта по основным сценариям с двумя участницами. Ещё отдельно — нынешняя бета у друзей с первыми пользователями. Количество исследовательских интервью, участников тестов и пользователей беты не складываем.

## Что означают 69, 56 и 50

- **69** — исходное число ответов до удаления части записей, по пояснению автора.
- **56** — число сохранившихся заполненных записей на первом листе `Sheet`, диапазон A2:A70; 56 уникальных ID. Внутри этого диапазона 13 полностью пустых строк. Это очищенный текущий срез, а не исходный объём опроса.
- **50** — выбранный автором целевой срез на листе `Салатовые и зеленые`, A2:A51; 50 уникальных ID. Строка 52 повторяет подписи, строка 53 содержит итоги — они не входят в N.

Важно: сам факт наличия 70 строк не доказывает 69 сохранившихся ответов. Исторический объём известен из пояснения автора. Для графиков кейса используем целевой лист N=50.

## Проверенные значения для графиков кейса

Лист `Салатовые и зеленые`, строки 2–51. Подсчёт: число непустых отметок в соответствующем столбце, по одному ответу на уникальный ID. Результаты совпадают с сохранённой строкой итогов 53.

Что раздражает в готовке и покупках; формулировка вопроса разрешает выбрать до трёх вариантов:

- Не знаю, что приготовить: **35 из 50 (70%)**, AU2:AU51; итог AU53=35.
- Продукты портятся: **33 из 50 (66%)**, AX2:AX51; итог AX53=33.
- Покупаю лишнее или забываю нужное: **27 из 50 (54%)**, AW2:AW51; итог AW53=27.
- Подсчёт КБЖУ / диеты усложняет готовку: **13 из 50 (26%)**, BA2:BA51; итог BA53=13.

Где сохраняют и ищут рецепты; один респондент может иметь отметки в нескольких столбцах:

- Поисковик: **33 из 50 (66%)**, N2:N51; итог N53=33.
- Instagram / TikTok: **27 из 50 (54%)**, G2:G51; итог G53=27.
- Telegram / ВК: **19 из 50 (38%)**, H2:H51; итог H53=19.
- Нигде не сохраняю, решаю на ходу: **19 из 50 (38%)**, O2:O51; итог O53=19. Это вариант поведения из того же вопроса, не отдельный канал поиска.
- Приложения с рецептами: **3 из 50 (6%)**, L2:L51; итог L53=3.

Следствие для редактора: значения 35/33/27/13 и 33/27/19/19 на текущей странице соответствуют целевой выборке. Пересчитывать их в 38/35/28 из первого листа не нужно. Исправить нужно общий объём опроса, число интервью и подписи выборки.

## Критерии отбора: что можно сказать точно

По пояснениям Дианы второй лист — выбранная аудитория с регулярной готовкой. В посте 44 критерии сформулированы как готовка раз в три дня или чаще и минимум одна проблема планирования питания.

Однако в текущем целевом листе D2:D51: 17 ответов «Каждый день», 32 «Каждые 2-3 дня» и один «Раз в неделю» (D47). Поэтому пока безопаснее писать «50 участников, близких к целевой аудитории», как сформулировала Диана, а не утверждать, что все 50 строго прошли одинаковый частотный фильтр. Строку не исключали и исходную таблицу не меняли. При дальнейшем описании строгого скринера нужно уточнить причину этого включения.

Уверенное пользование цифровыми сервисами не подтверждено как отдельный критерий отбора в просмотренной анкете и посте. Не добавлять его к методике без основания.

## Интервью, тесты и бета

- **Четыре исследовательских интервью** — подтверждение Дианы и четыре столбца в исходной таблице. Число 3 из кейса устарело; число 5 из поста 47 сохраняется только как историческая формулировка источника и не используется как актуальный итог.
- **Первое сценарное тестирование с двумя участницами** — отдельные наблюдения о работе интерфейса. Не выдавать за дополнительные исследовательские интервью, повторную проверку исправлений или репрезентативную оценку продукта.
- **Работающая бета у друзей** — актуальное уточнение автора в чате. Есть первые пользователи, команда доделывает функции, полноценное тестирование и оплата ещё впереди. Дата запуска, общее число пользователей и показатели использования не уточнены.
